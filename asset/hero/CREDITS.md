# 홈 히어로 이미지

홈 맨 위에서 자동으로 넘어가는 이미지 3장이다. 제작: 윤수영.

| 순서 | 파일 | 이미지 속 문구 |
| --- | --- | --- |
| 1 | `hero-01.webp` | 모든 유출 사고를 한곳에 · LeakBase |
| 2 | `hero-02.webp` | LeakBase · 국내 개인정보 유출 사고 아카이브 |
| 3 | `hero-03.webp` | 유출은 멈추지 않습니다 · LeakBase |

- 원본은 2000×800 png(비율 5:2)이고, 사이트에는 1600×640 webp로 변환해 넣었다(2026-11-17).
- 이미지 속 글자는 이미지 파일에 들어 있다. 문구를 바꾸려면 이미지를 다시 만들어야 하고, 화면 읽기 프로그램용 설명은 `js/app.js` 홈 화면의 `HERO` 목록(alt)에 적혀 있다.
- 실제 기업 로고나 실제 사고 사진이 아니라 사이트 소개용 이미지다.
- 제작 도구·제작일·프롬프트는 수영이 이 파일에 이어서 기록한다.
