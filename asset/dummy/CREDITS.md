# 이미지 출처 기록 (asset/dummy)

**AI 생성 실습용 이미지 · 실제 기업 로고 아님 · 실제 사고 사진 아님**

더미(가상) 사고 카드에만 사용하는 가상 기업 로고 40개입니다. 실제 사고에는 사용하지 않습니다.

| 항목 | 내용 |
| --- | --- |
| 제작 방식 | 생성형 AI로 제작 (AI 생성 여부: 예) |
| 제작 도구 | Gemini |
| 제작일 | 2026-11-09 ~ 2026-11-13 |
| 원본 | 가로형 16:9(1376×768 PNG 36개, 1024×572 WebP 4개) |
| 사용 파일 | 마크를 중심으로 정사각형으로 잘라 360×360 WebP로 변환 (파일당 8KB 이하) |
| 보정 | 21번은 배경의 연한 사각형 자국을 흰색으로 정리 |
| 배정 방식 | 같은 분야의 더미 사고에 최신 사고부터 순서대로 돌려 가며 배정(JSON의 `thumbnail` 필드) |

## 제작 프롬프트 (요약 없이 원문)

```
지금부터 가상의 기업 로고 심볼 마크를 한 장씩 만들 거야. 내가 "마크:"로 한 줄을 보낼 때마다 이미지를 딱 1장만 만들어줘. 여러 개를 한 이미지에 합치거나 격자로 나열하지 마.

[공통 스타일]
- 가로형 16:9, 1600x900, 배경은 순백색(#FFFFFF) 단색
- 실제 기업의 브랜드 심볼 마크처럼 만들 것. 화면 정중앙에 추상적인 기하학 도형 마크 1개만, 화면 높이의 약 45% 크기
- 지정한 색 1~2색만 사용한 플랫 벡터. 지정하지 않은 색은 절대 쓰지 말 것
- 그라데이션, 그림자, 입체감, 반짝임, 배경 장식 없음
- 도형은 단순하고 대담하게. 작게 줄여도 모양이 알아보일 정도로 간결하게
- 원, 사각형, 삼각형, 곡선 같은 기본 도형을 조합하거나 여백(네거티브 스페이스)을 활용
- 자물쇠, 방패, 열쇠, 서버, 지도 핀 같은 설명용 아이콘은 사용하지 않는다

[제외]
- 글자, 알파벳, 숫자, 한글, 워터마크 금지 (이니셜 모양도 금지)
- 실존 기업과 서비스의 로고를 닮거나 따라한 디자인 금지
- 실존 인물, 사람 얼굴 금지
```
